DMP Description

This Data Management Plan describes the management of the main data, data models, and software components of the OpenCitations infrastructure.
It covers the OpenCitations Data Model(OCDM), OpenCitations Index, OpenCitations Meta, and the software used to ingest, process, validate, and manage data compliant with the OpenCitations Data Model.

The purpose of the plan is to document how these research objects are created, processed, stored, documented, accessed, shared, preserved, and reused, including their formats, identifiers, provenance, licensing, and data quality procedures.

The DMP is intended to provide a structured and machine-actionable description of the data management practices adopted within OpenCitations.

OpenCitations Data Model (OCDM)

Description

The OpenCitations Data Model is an RDF-based model for representing bibliographic entities, citations, identifiers, agents, publication venues, and provenance. It reuses the SPAR Ontologies, PROV-O, and other established vocabularies to provide a consistent semantic representation across OpenCitations datasets and external projects.

Data Quality Assurance

OCDM reuses established ontologies and follows a documented ontology development and evaluation process. Extensions use SAMOD with motivating scenarios, competency questions, and a glossary of terms. OCO has been evaluated against JATS/XML data, compared with other bibliographic data models, and tested against requirements from early adopters. New use cases are used to identify and address gaps in the model.

oc-index (OpenCitations Index software)

Description

oc-index is a Python package for producing citation data for the OpenCitations Index. It resolves external identifiers in citation tables to OpenCitations Meta Identifiers (OMIDs), converts citation links into OMID-to-OMID relationships, and generates citation entities compliant with the OpenCitations Data Model. The software is open source and released under the ISC License.

Data Quality Assurance

Development is managed with Git and supported by an automated test suite and GitHub workflows. Static type checking is performed with Pyright, and code changes can be reviewed through GitHub pull requests. Data produced by the ingestion workflow is also subject to validation and post-ingestion monitoring.

oc_ocdm (software for handling OCDM-compliant data)

Description

oc_ocdm is an open-source Python library for creating and manipulating RDF data compliant with the OpenCitations Data Model. It provides object-oriented interfaces for bibliographic resources, agents, identifiers, provenance, and dataset metadata, with support for validation, change tracking, serialization, and synchronization with RDF stores. The software is released under the ISC License.

Data Quality Assurance

oc_ocdm uses Test Driven Development, automated tests, benchmarks, and GitHub workflows to check software changes. The library also validates entity operations against OCDM constraints. Change tracking and provenance record modifications to RDF entities, while versioned releases and the changelog document changes to the software.

OpenCitations Index

Description

The OpenCitations Index is an open collection of citation links integrated from multiple scholarly data sources. Citations are normalised as OMID-to-OMID relationships, deduplicated, and represented according to the OpenCitations Data Model. Each citation is identified by an Open Citation Identifier (OCI) and can include metadata, provenance, and change-tracking information.

Data Quality Assurance

The ingestion workflow normalises external identifiers and uses OpenCitations Meta to map identifiers referring to the same bibliographic resource. These mappings allow duplicate citation links from different sources to be identified and removed. Provenance and change-tracking records support traceability, while validation is applied before publication.

OpenCitations Meta

Description

OpenCitations Meta is an open bibliographic metadata database for scholarly resources involved in citations indexed by OpenCitations. Records are automatically curated and deduplicated using persistent identifiers, and entities are assigned OpenCitations Meta Identifiers (OMIDs). Curated metadata are represented as OCDM-compliant RDF, with provenance and change-tracking records documenting the source and history of each entity.

Data Quality Assurance

Before RDF conversion, the Curator performs identifier-based deduplication, enrichment, normalization, and error correction. Entities are merged only when shared identifiers establish that they represent the same resource. Provenance and change-tracking records preserve the history of each entity. META-CSV data can be validated before ingestion, and automated monitoring queries can detect database-level errors after ingestion.

oc_meta (OpenCitations Meta software)

Description

oc_meta is open-source Python software for managing bibliographic metadata in OpenCitations Meta. It processes structured CSV metadata, performs automated curation, and generates RDF compliant with the OpenCitations Data Model. The software also records provenance and change tracking for bibliographic entities and is released under the ISC License.

Data Quality Assurance

oc_meta is maintained with Git and an automated test suite integrated with GitHub workflows. Development tools include pytest and coverage for testing, Pyright for static type checking, and Ruff for code analysis. Software changes are documented through versioned releases and the project changelog.
