The OpenCitations team dedicates staff time and technical infrastructure to maintaining OCDM. This includes updating the model specification and related ontologies, documenting and evaluating changes, and maintaining the public GitHub repository for version control and collaborative development.

description
OpenCitations dedicates staff time and computational infrastructure to developing, testing, maintaining, and running the Index ingestion software. Resources support the Python codebase, citation processing, identifier resolution through OpenCitations Meta, citation and provenance generation, and updates to the Index database and published distributions. Development and version control are managed through the OpenCitations GitHub repository.

Resources support the Python codebase, automated tests, dependency management, documentation, PyPI releases, and compatibility with OCDM and related OpenCitations software. Development and version control are managed through the OpenCitations GitHub repository.

description

description

Resources also support provenance and change tracking, dataset distributions, APIs, and query services. The work described in the canonical publication was partially funded by OpenAIRE-Nexus and GraspOS.

OpenCitations dedicates staff time and computational infrastructure to developing, testing, maintaining, and running oc_meta. Resources support the Python codebase, automated curation, RDF and provenance generation, testing, software releases, and updates to the OpenCitations Meta database. Development and version control are managed through the OpenCitations GitHub repository.

OpenCitations Meta is an open bibliographic metadata database for scholarly resources involved in citations indexed by OpenCitations. Records are automatically curated and deduplicated using persistent identifiers, and entities are assigned OpenCitations Meta Identifiers (OMIDs). Curated metadata are represented as OCDM-compliant RDF, with provenance and change-tracking records documenting the source and history of each entity.

description
This Data Management Plan describes the management of the main data, data models, and software components of the OpenCitations infrastructure.<div>It covers the OpenCitations Data Model(OCDM), OpenCitations Index, OpenCitations Meta, and the software used to ingest, process, validate, and manage data compliant with the OpenCitations Data Model.</div><div>The purpose of the plan is to document how these research objects are created, processed, stored, documented, accessed, shared, preserved, and reused, including their formats, identifiers, provenance, licensing, and data quality procedures.</div><div>The DMP is intended to provide a structured and machine-actionable description of the data management practices adopted within OpenCitations.</div>
